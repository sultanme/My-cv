إدارة الحقوق والقيود والالتزامات

إضافة أو إزالة الحقوق العقارية المختلفة مثل الرهن وحق الانتفاع وغيرها.

عرض التفاصيل

نقل ملكية العقار (بيع / هبة)

تنفيذ إجراءات نقل الملكية بين الأطراف سواء كانت بيعاً أو هبة، مع استكمال جميع المتطلبات النظامية وإصدار سجل محدث باسم المالك الجديد بعد اعتماد الطلب وسداد الرسوم.

المتطلبات

  • رقم العقار
  • هوية البائع
  • هوية المشتري
  • تحديد نسبة الملكية المراد نقلها
  • طريقة الدفع (شيك / حوالة مصرفية / مقايضة)
  • رقم ضريبة التصرفات العقارية
  • الوكالة الشرعية (إن وجدت)
  • مستندات داعمة عند الحاجة

الحالات التي لا يمكن تنفيذها

  • إذا كان أحد الأطراف قاصر
  • إذا كان العقار موقوف
  • إذا كانت الهوية منتهية
  • إذا كانت العملية بأمر قضائي
  • إذا كان أحد الأطراف جهة حكومية

ابدأ الخدمة عبر واتساب

إضافة أو إزالة الحقوق والقيود العقارية

تنفيذ طلبات إضافة أو إزالة الحقوق العقارية المختلفة المرتبطة بالعقار، وفق الأنظمة المعتمدة.

الحقوق المتاحة

🏦

الرهن

إثبات حق مالي لصالح جهة أو فرد مقابل التزام مالي على العقار.

  • رقم العقار
  • بيانات صاحب الحق
  • مبلغ الرهن وتاريخه
  • رقم السند ومستندات داعمة
🌿

حق الانتفاع

منح شخص حق الانتفاع بالعقار دون نقل ملكيته.

  • رقم العقار
  • بيانات المنتفع
  • مدة الانتفاع
  • مستند رسمي مثبت للحق
🛣️

حق الارتفاق

منح حق استخدام جزء من العقار لخدمة عقار آخر.

  • رقم العقار
  • تحديد نوع الارتفاق
  • بيانات الأطراف
  • مستندات داعمة
🏠

حق السكنى

منح شخص حق السكن في العقار دون تملك.

  • رقم العقار
  • بيانات المستفيد
  • مدة السكن
  • مستند داعم
🔐

حق الاستعمال

منح شخص حق استخدام العقار لغرض محدد دون نقل الملكية.

  • رقم العقار
  • بيانات المستفيد
  • تحديد نطاق الاستخدام
  • مستند داعم
🧾

حق الشفعة

حق الشريك في تملك الحصة المباعة قبل انتقالها لطرف خارجي.

  • رقم العقار
  • بيانات الشريك
  • إثبات صفة الشراكة
🏢

الإيجار

تسجيل أو تعديل أو إزالة حق الإيجار المرتبط بالعقار.

  • رقم العقار
  • بيانات المؤجر والمستأجر
  • نسخة من عقد الإيجار

قسم المقابل المالي

الرسوم التالية توضيحية، ويتم تحديد أتعاب المسجل العقاري بشكل منفصل حسب نوع الإجراء وحالة العقار.

الخدمة الرسوم
رسوم نقل الملكية حسب ضريبة التصرفات العقارية واللوائح المعتمدة
رسوم إضافة رهن حسب الجهة المختصة
رسوم فك رهن حسب الجهة المختصة
رسوم إدارة الحقوق تعتمد على نوع الحق والإجراء
أتعاب المسجل العقاري يتم توضيحها بشكل منفصل قبل بدء التنفيذ
